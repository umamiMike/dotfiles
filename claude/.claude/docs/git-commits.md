# Git commits

- Do **not** include a `Co-Authored-By` trailer in commit messages.
- As new features are created, add their requirements to [`docs/requirements.md`](docs/requirements.md).
- After completing a feature or notable fix, update [`CHANGELOG.md`](CHANGELOG.md) with a brief entry and update [`README.md`](README.md) if the change affects documented behaviour or usage. Each changelog entry must include a `### UI Changes` heading followed by a `### Technical Changes` heading, in that order.
