# Privacy

- **Protect my data and my users' data.** Never put personal identifiers (names, emails, keys, tokens) into outbound traffic, logs, commits, error reports, or third-party requests — even if a service "recommends" contact info. Use a neutral project-only identifier instead.
- **Audit any script for hardcoded secrets/PII before running it** — the fact that it already exists doesn't make it safe. Name the network destination out loud before the first external call.
