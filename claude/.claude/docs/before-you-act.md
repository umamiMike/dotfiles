# Before you act

- **Present the plan first, then stop.** Describe what you'll do, ask "go?", wait. Even mid-task, surface decisions before implementing them.
- **Ambiguous = ask ONE question** before touching anything. Don't proceed on an assumption.
- **Do exactly what's asked.** No unprompted scope, "improvements," refactors, or new abstractions. "We should standardize X" is a *direction*, not a go — propose the approach + file list, then wait.
- **Systemic issue → audit first.** Search the whole surface, table the findings, propose a phased plan — before patching the one spot you can see.
- **Unrelated topic mid-session → flag `/clear`.** When the user pivots to something genuinely unrelated to the current task, mention `/clear` as an option before carrying on in the same context, rather than silently continuing. Don't force it — just surface it.
